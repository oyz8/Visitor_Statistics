使用说明
1

添加追踪图片

在「图片管理」页面点击「＋ 添加一行」，先填写标识符（例如 nezha），然后点击缩略图选择任意本地图片（也可以直接拖拽）。

  • 标识符决定一切：填 nezha → 上传到 Git 的文件名就是 nezha.png，访问链接为 /nezha.png
  • 本地图片叫什么名字无所谓（比如 sssss.png 也行），只取其图片内容
  • 标识符只允许字母、数字、下划线、连字符，长度 1–64
  • 支持 PNG / JPG / GIF / WebP / SVG，单张 ≤ 8 MB
2

保存并部署

一次性把所有图片添加好，然后点击「保存并部署」。系统会：

  • 把新图上传到 Git 仓库（文件名 = 标识符.扩展名）
  • 自动清理被替换/删除的旧图
  • 自动触发 Pages 部署，弹窗显示完整进度
  • 构建完成后 30 秒自动刷新，无需手动 F5
3

获取访问链接

部署完成后，把链接嵌入到任何 HTML 页面或邮件正文：

<img src="https://你的域名/nezha.png" width="1" height="1">

访客打开页面时，浏览器请求该图片 → Worker 拦截 → 记录 D1 → 返回图片。

4

详细日志

每次有效访问（非爬虫）都会写入 D1 详细日志表，包含：时间、标识符、IP、归属地、运营商、设备、系统、浏览器、内核、来源。可在「详细日志」页面按日期 / 标识符 / IP 筛选。

5

Telegram 通知

每个 IP 在 60 秒内只推送一次通知；同 /24 段 IP 也共用一次冷却，避免同机房批量访问刷屏。爬虫 UA 与测速工具 Referer 不推送。

消息中的「👤 管理仪表盘」按钮地址自动使用本次请求的域名，无需任何配置。

6

访客统计访问监控

登录页标题前的云图标 /_panel.svg 是内置追踪点：只有未登录访客打开登录页时才会触发追踪。

  • 已登录用户刷新页面不会重复触发
  • 退出登录后再次访问会重新触发
  • 概览与详细日志中显示为 管理面板
7

数据存储

  • Git 仓库 — 图片二进制 public/pic/{标识符}.{扩展名}
  • D1 — 详细日志 visits + 汇总 daily_summary + 图片索引 img_index（永久保留）
